# E2E run: the PiKVM computer-use MCP server against tools/fake-kvmd (2026-11-03)

The real `@pikvm/mcp` handler, the real Desk (`src/server/agent/desk.ts`: its own kvm-engine link over `ws`, snapshots over HTTP, the reference frame, the lease), and the real kvmd proxy (`src/server/proxy/kvmd.ts`) with its HID tap, in front of `tools/fake-kvmd`. The model side is an MCP test client (`@pikvm/mcp/testing`); there is no browser and no chat server yet, so the approval and the person's mouse are a scripted approver and a `ws` client on the proxy. Suite: `tests/agent-desk.test.ts` (37 cases) and `tests/hid-tap.test.ts` (7), run with `yarn test`; the kvm-engine and mcp unit suites run with `yarn workspace <name> test`.

The records below are `GET /__fake/hid`, one run of the scenario with a 1920x1080 target (so the model's frame is the 1280x720 downscale) and a pointer step count collapsed for reading.

| Case | Observed | Result |
| --- | --- | --- |
| each tool reaches kvmd as the right calls | screenshot: `GET /api/streamer/snapshot?allow_offline=1` with the Pi's credentials; click, drag, scroll, type, key, power: the HID and ATX records below and in the suite | pass |
| coordinates round-trip at four resolutions (320x180, 1280x720, 1920x1080, 3840x2160), absolute mouse | the unit sent equals the engine's `pixelToNorm`, `normToPixel` returns the pixel, and the native pixel under it is the centre of the reference pixel | pass |
| a relative mouse | swept to the corner, then stepped; the reports add up to the native pixel; no absolute move is sent | pass |
| `stale_frame` | input before any screenshot, and after a resolution change, is refused with the reason; a new screenshot clears it | pass |
| a person's input through the proxy | a move, button, wheel, key, a binary frame and a paste each release control, abort the action in flight, lift the held button and keys, and the next call says `control_released`; a heartbeat does not; input from before the run does not; moving the mouse back does not return control; `handBack` or a new message does | pass |
| approvals | risky chords, drags, typed line breaks and no recent screenshot ask; plain clicks, short text and looking never do; a denial and "nobody to ask" send nothing | pass |
| the desk | two conversations contend and the second is told; a lease that ran out is taken back; `busy()` holds the idle jiggler off and releases it at the end of the run | pass |
| credentials | every HTTP call and the HID socket carried `X-KVMD-User`; the password, the header names and the address appear in no tool result, error, tool list or activity event; an unreachable Pi is reported without either | pass |
